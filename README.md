# cscspa — Carrasco Stuardo Consultorías SpA

Proyecto de transformación digital y rescate para pymes y comercios locales en Chile.

## Misión
Recuperar activos digitales abandonados o sobrecostosos, y entregar tecnología liviana y operativa para que el negocio agende y cotice hoy mismo.

## Oferta MVP
1. **Diagnóstico gratuito** de tu sitio actual (velocidad, accesos, estructura)
2. **Landing page rápida** o corrección de sitio existente
3. **Agendamiento por WhatsApp** wa.me configurado en 24h
4. **Soporte técnico operativo** (hardware, upgrades, diagnóstico)

## Diferencial
Mientras agencias grandes venden paquetes rígidos y caros, nosotros:
- Rescatamos lo que ya tienes (no obligarte a empezar de cero)
- Tecnología liviana, sin licencias mensuales innecesarias
- Precio accesible para pymes y comercios de barrio
- Acompañamiento humano + IA aplicada a la operación diaria

## Segmento
Ópticas, talleres, servicios técnicos, comercios locales, profesionales independientes.
